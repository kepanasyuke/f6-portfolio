# 07 · Ops Agent

Инвентарь серверов, метрики состояния и чек-листы укрепления — та часть работы аналитика, которая про администрирование, а не про отчёты.

## Что проверяется

| Метрика | Порог warn | Порог critical |
| --- | --- | --- |
| занятость диска | 80 % | 92 % |
| память | 85 % | 95 % |
| LA 1m | 6 | 10 |
| пропущено патчей | 5 | 12 |
| дней до истечения сертификата | 21 | 7 |
| неудачных входов за сутки | 10 | 40 |

Значения в стенде детерминированные (md5 от имени хоста и метрики), поэтому тесты и демо воспроизводимы офлайн. В боевой установке на это место встают node_exporter, WMI и SSH-инвентаризация.

## API

| Метод | Путь | Смысл |
| --- | --- | --- |
| GET | `/api/overview` | парк серверов и агрегаты по статусам |
| GET | `/api/hosts` | карточки хостов с метриками |
| GET | `/api/hosts/{name}` | один хост |
| POST | `/api/hosts` | добавить хост в инвентарь |
| POST | `/api/hosts/{name}/check` | прогнать проверки, записать в журнал |
| POST | `/api/check-all` | прогон по всему парку |
| GET | `/api/problems` | только warn/critical |
| GET | `/api/playbook?os=` | чек-лист Linux или Windows |
| GET | `/api/journal` | журнал действий |
