# 05 · Typosquat Radar

Поиск доменов, похожих на защищаемый бренд, и оценка риска.

## Техники генерации

| Техника | Пример для `f6security.example` |
| --- | --- |
| пропуск символа | `f6ecurity.example` |
| дублирование | `f6ssecurity.example` |
| перестановка | `fs6ecurity.example` |
| омоглифы (кириллица) | `f6sеcurity.example` |
| замены `s→5`, `e→3`, `rn→m` | `f6s3curity.example` |
| дефис | `f6s-ecurity.example` |
| смена TLD | `f6security.co` |
| поддомен | `login.f6security.example` |

## Скоринг

`risk = база(расстояние Левенштейна) + бонус за рискованный TLD + бонусы за сигналы + бонус за нелатинский скрипт`, всё зажимается в 0–100. Вердикт: `critical ≥ 75`, `high ≥ 55`, `medium ≥ 35`, иначе `low`.

Сигналы (регистрация, MX, HTTP-код, возраст домена) в стенде синтетические и детерминированные: они считаются из md5 домена, поэтому демо воспроизводимо без сети. В продакшне на это место встают RDAP/DoH/краулер.

## API

| Метод | Путь | Смысл |
| --- | --- | --- |
| POST | `/api/scan` | сгенерировать и оценить варианты, сохранить в историю |
| GET | `/api/check?domain=&brand=` | точечная оценка домена |
| POST/GET | `/api/watchlist` | список наблюдения |
| GET | `/api/scans` | история сканирований |
| GET | `/api/stats` | агрегаты и список техник |
