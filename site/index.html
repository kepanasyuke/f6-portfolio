Линтер

Правила кода стенда

0 нарушений
правило 1

Одна точка выхода

В функции ровно один return. Ветвление — выражением, а не ранним выходом.

F6S002
правило 2

1–2 инструкции

Тело функции — не больше двух инструкций без докстринга. Крупные шаги собираются композицией.

F6S001
правило 3

Без while / break / continue

Циклы выражаются генераторами и рекурсией, обход графа уходит в рекурсивный CTE.

F6S003

Правила проверяются тремя инструментами: ruff.toml (ошибки, импорты, упрощения), .pylintrc (лимит инструкций и ветвлений) и собственный AST-чекер lint/check_style.py — он и ловит один выход, две инструкции и запрещённые конструкции. 

.\.venv\Scripts\python.exe lint\check_style.py .

Локально

Запуск стенда

Один раз поставить зависимости:

python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt

Поднять все сервисы и этот сайт:

.\run-all.ps1

Остановить:

.\stop-all.ps1
