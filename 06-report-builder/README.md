# 06 · Report Builder

Сборка отчётов для закрытого портала Threat Intelligence: структурированное описание угрозы → Markdown по шаблону → HTML-превью и файл `.md`.

## Шаблоны

| id | Назначение |
| --- | --- |
| `threat` | кампания и инфраструктура: резюме, IOC, наблюдения, рекомендации |
| `incident` | брифинг по инциденту |
| `actor` | профиль злоумышленника |

Обязательные секции не пустуют: если блок данных не передан, секция в отчёт не попадает.

## Рендер Markdown

Собственный конвертер без зависимостей: заголовки `#`–`###`, списки `-` и `1.`, цитаты `>`, таблицы `| … |`, горизонтальная линия `---`, инлайн `**жирный**`, `` `код` ``, `[ссылка](url)`. Весь входной текст экранируется, поэтому HTML из тела отчёта не исполняется.

## API

| Метод | Путь | Смысл |
| --- | --- | --- |
| GET | `/api/templates` | шаблоны и уровни TLP |
| GET | `/api/sample` | демонстрационный набор данных |
| POST | `/api/preview` | собрать отчёт без сохранения |
| POST | `/api/reports` | собрать и сохранить (SQLite) |
| GET | `/api/reports` | история |
| GET | `/api/reports/{id}` | отчёт с HTML |
| GET | `/api/reports/{id}/markdown` | выгрузка `.md` |
| GET | `/api/metrics` | счётчики по шаблонам |
